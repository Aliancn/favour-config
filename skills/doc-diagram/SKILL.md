# 文档插图规范

这张图会被同事反复看，不是一次性截图。目标只有两个：**一眼看懂流程方向**，**看着不像 PPT 模板**。

本 skill 是活文档，会持续累积（见文末「维护约定」）。

## 一、开工前的三问

1. **内容里有没有"循环"？** 有 → 用环形轨道（§三-A）。没有 → 用单行流水线。
2. **有没有"散出去再收回来"？** 有 → 主流程一条线，支线用彩色弧挂在旁边。
3. **要素超过 8 个？** 先合并语义相同的步骤（准备类脚本合并成一步、采集类动作合并成一个节点），合并后再画。图不是清单，不需要一个脚本一个框。

## 二、丑图清单（出现任意一条即重画）

| 丑在哪 | 为什么难看 | 改成 |
|---|---|---|
| 蛇形排版：第一行左→右、第二行右→左、第三行再左→右 | 视线被强行折返两次，读起来像走迷宫 | 闭合环路 / 单行流水线；回流只用一条弧线 |
| 直角折线箭头，大量 T 形交叉 | 交错处无法判断谁连谁 | 平滑贝塞尔弧；回流走环内侧，不跨主线 |
| 一排排等大矩形，无编号无层级 | 像 Excel 截图，读者不知道从哪开始 | 环上站点加圆形编号；入口/出口用淡色"在环外"样式 |
| 菱形判断框满地爬 | 菱形占地方、文字被挤成两行，还会引入大量回流箭头 | **判断用分叉表达**：主线继续走，支线画一条彩色弧 + "是 / 否"标签 |
| 整块高饱和填色区分类型 | 色块感重，像模板 | 白卡片 + 1px 细描边 + 极淡投影；类型靠编号底色区分 |
| 环心 / 画布中央大片死白 | 画面松散，像没画完 | 环心放该回路的定义和约束（标题 + 两行小字） |
| 节点里塞长句、段落 | 图变成文档的截图 | 节点标题 ≤ 8 字；细节留给正文，图只画骨架 |
| 用 `<km-drawio>` | 要手算坐标、画布会裁掉越界路径、竖边标签被旋转 90°、`text;` 样式渲染成带框字 | **一律改用 `<km-html>` 内联 SVG** |
| 图宽超过正文栏 | 出现横向滚动条或被压扁 | SVG 宽 920 + `style="max-width:100%;height:auto"` |
| 装饰性图标、emoji、渐变光晕堆砌 | 噪音 | 只保留一种层级信号：线宽 + 字号 + 颜色克制 |

## 三、范式库

### A. 环形轨道（有循环时默认用这个）

把回路画成**一条闭合轨道，只朝一个方向转**。入口从上方汇入第一个站点，出口从最后一个站点下方离开。

```
        [入口1]
           ↓
        [入口2]
           ↓
  ①───②───③───④          ← 顺时针，站点带编号
  ↑            ↓
  ⑦───⑥───⑤
  ↓
        [出口]
```

规则：

- **站点编号 1…n**，顺序即流程顺序；编号圆用低饱和色，判断节点用暖色（琥珀）区分。
- **入口 / 出口节点在环外**：淡紫底、圆角、无编号 —— 让人一眼看出"这两个不在回路里"。
- **分叉不打散环**：判断节点的"否"分支从卡片侧边画一条**彩色弧**回到前序站点（弧画在环内或环外均可），"是"分支继续沿环走。标签写在弧旁边，不写在线上。
- **回流轨道与主轨道不同色**（见调色板 `RAIL_L`），所有"往回走"的连线统一这个颜色。
- **环心写这个环的定义**：大字标题（字间距拉开放）+ 一到两行约束小字。
- 站点在环上的间距 ≥ 25px，太挤时减站点不加行。

### B. 单行流水线（无循环）

一条水平主线，步骤从左到右，**永远不折返**。分支向下挂，回归线走主线下方一条单独的弧。

### C. 分层架构（系统 / 模块关系）

横向分层带（自下而上或自上而下），同层并列，层间用细箭头。不要画成竖排方框串。

### D. 对比 / 决策矩阵

**不要去画图**，用 `<table>`。表格才是这类内容的最佳形态。

## 四、实现规范

### 容器

```xml
<km-html><![CDATA[
<svg xmlns="http://www.w3.org/2000/svg" width="920" height="640" viewBox="0 0 920 640"
     style="max-width:100%;height:auto" font-family="PingFang SC,Hiragino Sans GB,sans-serif"> … </svg>
]]></km-html>
```

- 必须 CDATA，否则 HTML 会被当 XML 解析掉。实测学城能正常渲染 CSS / 内联 SVG / script（2026-10 验证）。
- **只把图放进去**；正文仍然用 `<p>/<h3>/<table>` 原生节点 —— km-html 是孤岛，里面不能划词评论、不能选区编辑。

### 调色板（Rosé Pine Dawn 系，柔和浅色）

| 用途 | 值 |
|---|---|
| 卡片底 / 描边 | `#ffffff` / `#ece6df` |
| 标题 / 说明文字 | `#4f4a57` / `#9a939f` |
| 环外节点（入口、出口） | 底 `#f8f6fb`，边 `#e7e1ef`，字 `#6b5b86` |
| 判断节点 | 底 `#fdf9f1`，边 `#eee1c9` |
| 主轨道 / 普通编号 | `#c2bab2` / `#9fadb2` |
| 回流轨道 / 回路编号 | `#b39fc4` / `#c2945e`（判断编号） |
| 环心标题 | `#8d8497`，加 `letter-spacing="3"` |

### 尺寸约定

- 卡片：圆角 14，高 46–56，宽 145–200，`filter="url(#sh)"`（`feDropShadow dy=1.5 stdDeviation=2.6 flood-opacity=0.11`）。
- 字号：卡片标题 13.5/600，说明与标签 10.5/400，环心标题 15/600。
- 编号圆：`r=9`，数字 10.5/600 白色，圆心距卡片左边 25，标题从 `x+43` 起排。
- 箭头：`stroke-width=2`，`markerUnits="userSpaceOnUse"`，`refX=8 refY=4`，箭头形 `M0,0.6 L8,4 L0,7.4 z`。
- 轨道转折用三次贝塞尔（`C`）而不是直角 `L`，控制点放在轨道外侧 50–80px 处。

**完整的生成器代码（helper 函数、卡片、胶囊、环形弧、多行环心标签）见 [references/svg-kit.md](references/svg-kit.md)，直接复制改坐标即可，不要从零手写。**

## 五、强制流程

1. **选范式**（§三），在纸上/注释里先写清：几个站点、哪个是判断、入口出口在哪。
2. **写 Python 生成 SVG**，用 `references/svg-kit.md` 的 helper。坐标全部用常量，方便改。
3. **本地渲染自检**：`rsvg-convert -w 1500 x.svg -o x.png`，然后用读图工具看，**不满意就改坐标重渲**。没看过渲染结果不许写进文档。
4. **抓最新文档 XML**（`getDocumentXml`）→ 替换/插入 `<km-html>` 节点 → `updateDocumentByXml --step-version <最新>`。
5. **回读校验**：重新 `getDocumentXml`，确认 `<svg width="920"`、环心标签文字都在，`km-drawio` 计数为 0。

## 六、交付前自检

- [ ] 主线只有一个方向，没有第二段折返
- [ ] 循环被画成闭环，且站点有编号
- [ ] 所有判断都是分叉 + 标签，没有菱形方框
- [ ] 回流线与主线不同色
- [ ] 环心 / 中央空白被定义文字填满
- [ ] 每个节点标题 ≤ 8 字
- [ ] 自己在 1500px 下看过渲染图，没有重叠、没有出界
- [ ] 文档里没有残留 `km-drawio`

## 七、维护约定

**本 skill 是活文档，每次画完图都应该回头更新它。**

- 画完发现某个版式不好看 → 把现象补进 §二「丑图清单」，写清"为什么难看"和"改成什么"。
- 摸索出新的好版式 / 新的组件写法 → 补进 §三「范式库」或 `references/svg-kit.md`，并加一句适用场景。
- 学城渲染能力有变化（比如哪天 `km-html` 被限制、或官方出了新的图表节点）→ 在本节顶部的「事实」里记一行日期 + 结论。
- 只写**可复用的一句话结论**，不要贴整段过程。旧的结论被推翻时直接改掉，不要保留错误信息。

已知事实（按日期累积）：

- 2026-10-27：`<km-html>` 的 CDATA 内 CSS / 内联 SVG / `<script>` 均正常渲染，存取往返无损；`getSimpleMarkdown` 会输出 `<!-- HTML 内容 -->` + 原始 HTML。
- 2026-10-27：`km-drawio` 的 renderer 忽略 `labelBackgroundColor` / `verticalAlign=top` / `horizontal=1`，竖边标签会旋转 90°，`text;` 样式渲染成带框的 `[文字]`；画布宽度 ≈ 节点右边界 − 左边界 + 80，越界路径被裁掉。已弃用。
- 2026-10-27：范式 A（环形轨道）在《内部场景》文档的两张图上验证通过，可作为范例基线。
